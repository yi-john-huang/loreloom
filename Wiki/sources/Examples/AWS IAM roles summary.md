# AWS IAM roles summary

This example page summarizes one Source. It shows the lightweight page format.

## Summary

The Source says that an IAM role is an AWS identity with permission policies. Trusted identities can assume a role. A role is not tied to one specific person. Role use involves temporary credentials.
