# Build or regenerate a Wiki page

```text
Follow AGENTS.md, .agents/policies/vault-policy.md, and
.agents/workflows/regenerate-wiki.md.

Target Wiki path:
- <EXACT PATH>

Authorized Knowledge inputs:
- <EXACT PATHS>

Question the page should answer:
- <QUESTION>

Build a clear synthesis using only the authorized inputs and their declared
Sources. Treat draft inputs as provisional and label conflicts or uncertainty.
Set generated: true, record every input, and preserve text between human block
markers byte-for-byte. Never cite the Wiki page as evidence and never silently
resolve contradictory sources.

Before writing, show the input coverage and proposed outline. After the
authorized edit, validate the vault and report changed conclusions, conflicts,
gaps, and required human review.
```
